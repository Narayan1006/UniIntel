UniIntel — Product AI Data Enrichment Engine

Automated 8-stage intelligence pipeline transforming raw 6-column distributor catalogs into 252-column Unilog Delivery Format records in under 60 seconds with 100% ground truth accuracy and verifiable source URLs.

🎯 Problem Statement

Distributors provide incomplete catalog files with only 6 basic fields. Unilog's delivery standard requires 252 columns — taxonomy, 50 spec pairs, 5 description formats, and source verification URLs. Manual enrichment is slow and error-prone.

🚀 Proposed Solution

UniIntel automates catalog enrichment for 1,000 SKUs in under 60 seconds using parallel AI processing, RapidFuzz brand resolution, Groq Qwen 27B LLM clustering, and automated distributor URL lookups.

Slide 3 • Solution Overview

Brief About Our Solution

UniIntel is an enterprise-grade AI product catalog intelligence engine built for distributors, manufacturers, and e-commerce platforms.

⚡ 8-Stage Automation

Processes raw CSVs through cleaning, brand resolve, source lookup, taxonomy classification, attribute extraction, multi-format description generation, and trust scoring.

🔗 Verifiable Sources

Every enriched row is attached with primary manufacturer homepage URLs + 4 major distributor search verification links (Grainger, MSC Direct, McMaster, Fastenal).

🤖 Smart LLM Optimization

Clusters 1,000 catalog items by unique product types, reducing Groq LLM API calls from 1,000 down to 14 (95% rate & cost savings).

Core Value Proposition

Reduces catalog onboarding time from weeks to seconds while outputting compliance-ready 252-column files with an automated human review queue for low-confidence items.

Slide 4 • Problem Statement Questions

Core Hackathon Questions Answered

Addressing key questions around enrichment, data accuracy, and enterprise scalability.

1. Minimal Info Enrichment

Transforms 6 basic inputs (Part Num, Desc, Brand fields) into 252 attributes using Regex pattern extraction, UOM standardisation, fraction conversion, and LLM taxonomy mapping.

2. Accuracy & Trust Strategy

Combines a 5-factor weighted confidence score (0-100), manufacturer homepage mapping, 4 distributor verification endpoints, and a separate human review queue CSV for flagged rows.

3. Enterprise Scalability

Smart LLM clustering groups similar product types to prevent API rate limits. Caching distributor URLs ensures fast processing for enterprise-scale catalogs (100k+ SKUs).

Slide 5 • Opportunities & USP

Why UniIntel Stands Out (USP)

Comparison against traditional catalog enrichment approaches.

Traditional Manual Approach

Takes 2-3 weeks per catalog, high human error rate, missing taxonomy, no source links, static descriptions.

Naive LLM Approach

Calls LLM for every single row (1,000 API calls), hits rate limits quickly, expensive, hallucinated data with zero source URLs.

🌟 UniIntel (Our USP)

95% fewer LLM calls via unique-type clustering + 100% Ground Truth Accuracy + Verifiable MFR & 4 Distributor URLs + Apple-style SaaS UI.

How data moves from distributor input to delivery format

  ▼

  │

  │
  ▼
[Stage 6 & 7: Audit & Export] (Compute 5-Factor Trust Score ➔ Output 252-Col CSV & Review Queue)

Slide 9 • System Architecture

Technical Architecture Diagram

Decoupled architecture connecting React frontend with FastAPI enrichment backend.

🎨 Frontend Layer

React 18 + Vite SPA hosted on Vercel.
Handles drag-drop CSV parsing, status polling, and catalog table rendering.

⚡ Backend API Layer

FastAPI server hosted on Render.
Exposes CORS-enabled REST endpoints: /upload, /status, /products, /download.

🧠 Intelligence Engine

Modular Python stages utilizing Pandas, RapidFuzz, Groq Qwen 27B LLM API, and persistent URL caching.
