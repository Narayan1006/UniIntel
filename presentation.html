Slide 1 • Overview & Problem Statement

UniIntel — Raw Data ➔ 252-Col Delivery Format

Distributors receive unstandardised 6-column product files. Unilog's delivery format requires 252 columns of structured taxonomy, specifications, 5-format descriptions, and verifiable source URLs.

❌ Input (Raw 6 Columns)

Unstructured, noisy distributor catalog rows:

  • Mfg_Part_Num: DCB518ASTS06G
  • Part_Desc: DIABLO 1/2X18 - SANDING BELT P150
  • E1_Brand: Freud
  • Unilog_Brand: Diablo
  • DIB_Brand: Diablo
  • Part_Manuf: Freud Inc.

✅ Output (252-Column Unilog Delivery)

Automated 8-stage AI enrichment output:

  • Canonical Brand: Freud Inc. / Diablo®
  • Taxonomy Classpath: Abrasives & Finishing > Sanding Belts
  • Descriptions: INVOICE_DESC (≤40 CAPS), MOBILE_DESC (50-90)
  • Attributes: 50 Spec Pairs (Grit: P150, Size: 1/2" x 18")
  • Verifiable URLs: MFR Homepage + Grainger, MSC, McMaster, Fastenal
Slide 2 • System Architecture

8-Stage Automated Enrichment Pipeline

Modular Python & FastAPI engine running 8 parallel stages to ensure 100% ground truth compliance.

STAGE 01
Ingest & Clean Data
UTF-8/Latin-1 auto-detection, placeholder stripping (N/A, TBD), MPN deduplication.
STAGE 02
Brand & Manufacturer Resolution
Fuzzy-matches manufacturer strings against canonical dictionary ("3 M Co" ➔ "3M Company").
STAGE 02B
Distributor Source URL Lookup
Fetches manufacturer homepage URLs + generates Grainger, MSC, McMaster, Fastenal search links.
STAGE 03
AI Taxonomy Classification
Keyword engine + Groq Qwen LLM fallback for Dept > Class > Fine classification.
STAGE 04
Attribute Extraction & UOM
Extracts up to 50 key/value pairs (Grit, Size, Voltage) & standardises UOMs/fractions.
STAGE 05
Multi-Format Descriptions
Generates INVOICE_DESC (≤40 CAPS), MOBILE_DESC (50-90), SHORT, LONG, & RETAIL descriptions.
STAGE 06
Trust Scoring & Audit Flags
Computes 5-factor weighted confidence score (0-100) & flags low-confidence items.
STAGE 07
252-Column CSV Export
Outputs exact Unilog Delivery Format CSV + human review queue CSV + metrics.json.
